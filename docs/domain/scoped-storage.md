independent roots. The existing physical parent/base tree supplies the containment
proof. The affected component must have unknown extent and views, without scalar
proofs; an unknown root relation still rejects all claims of independent allocation.
No nominal binding or source order establishes disjunction.

SP field, AIR contract or layout calculation. The SP 2.17/storage 1.5 producer may now
publish the more precise independent root next to an unknown component; older lower
versions reject this explicitly instead of misinterpreting the proof.

unresolved RENAMES in another record, and missing COPY in a separate ended unit.

continues to reject invented allocation and retains all alias relation provenance.

entry, with observed candidates kept separately by the frontend CLI.
