# ADR-0006 — Harness modular e lifecycle revisável

**Estado:** accepted_by_user_direction. **Data:** 2026-09-06. **Fontes:** SRC-HARNESS; SRC-PROMPTS; pedido atual; ver [registro](../../sources/index.md).

## Contexto

Agentes precisam de instruções persistentes ricas sem receber todo o repositório em cada prompt.

## Decisão

AGENTS curto roteia fontes canônicas e manifesto de checkpoint. Work item é transitório, backlog não é autorização, mesma branch/PR acumula checkpoints revisáveis.

## Consequências

Encerramento promove conhecimento, remove active e não presume merge. Aprovação de código não é autorização de merge.

## Alternativa rejeitada

Escolher o desenho apenas porque é fácil no modelo existente, copiar infraestrutura para o núcleo ou transformar exemplo/limitação de teste em regra semântica.

## Verificação

Os [invariantes](../invariants.md) e [evals](../../evals/catalog.md) operacionalizam a decisão. Enforcement runtime permanece planejado até existir executor e evidência. Mudanças exigem ADR sucessora ou revisão explícita, não edição silenciosa do significado.
