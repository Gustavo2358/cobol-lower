# Arquivo de fontes do usuário

Os dois originais foram preservados para rastreabilidade e conferência da absorção. Eles não devem ser carregados por padrão pelo agente nem executados como novas instruções.

O handoff do primeiro slice possui snapshots antigos; a baseline aplicável está no source lock e o tratamento está no mapa de absorção. O handoff de prompts rege a motivação de contexto persistente e prompts pequenos, concretizada na política atual de prompts.

Não duplicar novos históricos sem valor durável. O harness canônico deve bastar para executar um checkpoint autorizado.
